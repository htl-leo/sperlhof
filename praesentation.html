KI löst ein echtes Problem

Wie Claude mit Werkzeugen einen defekten Smart-Home-Server repariert hat

Das Problem: Ein Smart-Home ohne Updates

Ein Home Assistant-Server – das ist eine Art „Zentrale" für ein Smart Home, die Lampen, Heizung und andere Geräte steuert – konnte sich nicht mehr selbst aktualisieren. Das System war in einer Sackgasse:

Das Problem

Das Betriebssystem (HAOS 11.5) war sehr veraltet. Der Supervisor (Verwaltungsprogramm) bemerkte das und blockierte sich selbst – er wollte kein Update mehr durchführen.

Die Lösung

Claude hat das System mit verschiedenen Werkzeugen ferngesteuert und das Betriebssystem manuell auf Version 17.1 aktualisiert. Danach funktionierte alles wieder.

Henne-Ei-Problem: Das Betriebssystem war zu alt → der Supervisor blockierte Updates → das Betriebssystem blieb alt. Ein Kreislauf, der manuell unterbrochen werden musste.

Die verwendeten Werkzeuge

🔌

MCP-Server

Verbindet Claude direkt mit Home Assistant. Claude kann damit Zustände abfragen und Befehle senden.

🌐

Playwright (Browser)

Steuert einen Chrome-Browser automatisch. Wie ein Roboter, der auf Webseiten klickt.

⚡

WebSocket-API

Eine schnelle Echtzeit-Verbindung zur HA-Oberfläche – wie ein dauerhaft offenes Telefongespräch.

💻

Web-Terminal

Ein Terminal im Browser, über das echte Shell-Befehle auf dem Server ausgeführt werden können.

📋

Skills

Vordefinierte Anleitungen (Prompts), die Claude sagen, wie es bei bestimmten Aufgaben vorgehen soll.

Was ist ein MCP-Server?

Model Context Protocol

MCP steht für Model Context Protocol – ein Standard, mit dem eine KI wie Claude mit externen Programmen und Diensten sprechen kann.

Analogie: Stell dir vor, du bestellst eine Pizza per Handy. Dein Handy ist Claude, das Pizzeria-Bestellsystem ist der MCP-Server, und die Pizza ist die Information oder Aktion, die du brauchst. Du musst selbst nicht in die Pizzeria gehen – das Handy übernimmt die Kommunikation für dich.

Was kann ein MCP-Server für Home Assistant?

  • Gerätestatus abfragen: „Ist das Licht im Wohnzimmer an?"
  • Befehle senden: „Schalte die Heizung auf 21°C"
  • Konfigurationen lesen und ändern
  • Automatisierungen erstellen oder anpassen

Problem in diesem Fall: Weil das System „unsupported" (nicht unterstützt) war, hat der MCP-Server keine Verbindung bekommen. Claude musste einen anderen Weg finden – den Browser-Weg über Playwright.

Was sind Skills?

Skills sind vordefinierte Schritt-für-Schritt-Anleitungen für Claude. Sie werden als spezielle Befehle (z.B. /update-config) aufgerufen und erweitern Claudes Fähigkeiten für bestimmte Aufgaben.

Analogie: Stell dir vor, du hast ein Kochbuch. Du könntest aus dem Gedächtnis kochen – aber mit dem Kochbuch (= Skill) weißt du genau, welche Schritte du in welcher Reihenfolge machen musst, und vergisst nichts.

In diesem Projekt verwendeter Skill: update-config

Dieser Skill hat Claude erklärt, wie man die Konfigurationsdateien von Claude Code richtig liest und ändert – zum Beispiel um den MCP-Server einzutragen, ohne bestehende Einstellungen zu überschreiben.

Vorteile von Skills

  • Claude muss nicht alles selbst „wissen" – es gibt fertige Rezepte
  • Komplexe Aufgaben werden in klare Schritte aufgeteilt
  • Skills können für jeden Anwendungsfall angepasst werden
  • Fehler werden vermieden, weil der Ablauf klar definiert ist

Der Lösungsweg Schritt für Schritt

1
Verbindung herstellen

Claude hat versucht, über den MCP-Server mit Home Assistant zu kommunizieren. Das schlug fehl – der Server war im „unsupported"-Modus.

2
Browser-Weg wählen

Claude hat stattdessen Playwright genutzt und den Chrome-Browser automatisch zu http://192.168.2.212:8123 navigiert.

3
WebSocket-API verwenden

Über JavaScript in der Browser-Konsole (hass.callWS()) konnte Claude direkt mit dem Home-Assistant-System kommunizieren und Informationen abrufen.

4
Problem diagnostizieren

Die Abfrage ergab: HAOS Version 11.5, Supervisor Version 2025.08.3, Status: supported: false. Das System war 6 Hauptversionen hinter der aktuellen Version 17.1.

5
Terminal öffnen

Claude hat das SSH-Web-Terminal des Systems gefunden und geöffnet, um direkte Systembefehle ausführen zu können.

6
Supervisor reparieren

Befehl: ha supervisor repair → Das hat den Supervisor aus seinem blockierten Zustand befreit.

7
Aktuelle Version ermitteln

Mit curl wurde die aktuelle HAOS-Version direkt vom Internet abgefragt: Version 17.1 für das ODROID-N2-Board.

8
Update erzwingen

Befehl: ha os update --version 17.1 → Das System hat das Update durchgeführt und sich neu gestartet.

9
Erfolg bestätigen

Nach dem Neustart: HAOS 17.1, Supervisor 2026.03.2, supported: true. Problem gelöst!

Was macht KI dabei so besonders?

  • Plan B denken: Als der direkte Weg (MCP) scheiterte, hat Claude selbstständig einen anderen Weg gefunden.
  • Fehler lesen: Claude hat Fehlermeldungen analysiert und daraus die richtige Diagnose abgeleitet.
  • Werkzeuge kombinieren: Browser + WebSocket + Terminal wurden zusammen genutzt, um das Problem zu lösen.
  • Sicher arbeiten: Claude hat vor jedem kritischen Schritt überlegt, ob der Befehl sicher ist und ob er rückgängig gemacht werden kann.
  • Dokumentieren: Alle wichtigen Informationen wurden in einer Gedächtnis-Datei gespeichert, damit zukünftige Sitzungen den Kontext kennen.

Fazit

Eine KI wie Claude ist mehr als ein Chatbot, der nur Texte schreibt. Mit den richtigen Werkzeugen (Tools) kann sie:

  • eigenständig Probleme analysieren und lösen
  • echte Software und Hardware fernsteuern
  • mit APIs und Webservices kommunizieren
  • einen Browser wie ein Mensch bedienen
  • aus Fehlern lernen und den Kurs anpassen

Wichtig: Die KI hat hier nicht gezaubert – sie hat dieselben Werkzeuge benutzt, die auch ein erfahrener Systemadministrator verwenden würde. Der Unterschied: Claude konnte in Minuten analysieren, was sonst Stunden dauern könnte.
